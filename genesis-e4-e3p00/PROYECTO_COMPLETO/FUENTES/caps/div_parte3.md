# Parte III. Paquete 1000X y estrategia

El paquete reúne diez documentos ejecutivos. Son el resumen, el one-pager, el pitch deck, el capítulo de estrategia y el modelo de negocio. Son también el análisis financiero, el roadmap, el mapa de interesados, el tablero de riesgos y la lista de cumplimiento. Sus tablas y figuras llevan el prefijo X y el número del documento.
